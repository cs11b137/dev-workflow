# 场景：只改文档

1. 按 `docs/README.md` 的放置规则找到拥有该主题的文档与章节：用户可见行为 → 产品设计；机制 → 架构设计；格式 → `spec/`；通过标准 → 验收与测试。
2. 改写那一节（整合，不追加）。同一事实已在别处定义时，这里改成引用。
3. 只写规则，不写过程：讨论经过、修订历史交给 git。
4. 新增 ID 时用该前缀的下一个编号；已发布的 ID 不复用、不改含义，废弃的保留编号并标注废弃。
5. 修改根 `AGENTS.md` 时保持 ≤ 80 行：新细则放进所属文档，根文件只加一行触发条件与链接。
6. 运行 `python3 <插件根>/scripts/audit.py`，修到没有 ERROR；对照 diff 核对改到的路径、命令与术语。
7. 用 `docs(<scope>)` 提交；纯文档任务可以跳过代码测试，在交付说明里写明。

完成标准：审计没有 ERROR；diff 里的事实没有在第二处重复定义。
