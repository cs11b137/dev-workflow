## 2. 放置规则

- **入口要薄**：可启动的程序只做生命周期、装配与参数解析，业务逻辑放进按领域拆分的包或模块。
- **按领域拆**：包、目录与文件都用领域名（如 `seek.ts`、`video-store.ts`）；`utils`、`common`、`helpers`、`types.ts`、`manager` 这类按代码类型起的名字改为它实际所属的领域名。
- **生成物**：由脚本生成的文件注明生成入口，重建后提交，只通过生成入口修改。
- **临时产物**：截图、渲染结果、测试项目放仓库外的临时目录；有意维护的测试夹具放所属测试目录。
